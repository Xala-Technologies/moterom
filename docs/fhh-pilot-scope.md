# Frivillighetens Hus — pilotscope (utkast til møtet)

Ikke en signert avtale. Brukes til å bli enige om omfang før utvikling på live tenant.

## Forslag

- **Varighet:** seks måneder gratis prøveperiode (omtalt 13.10.2026; endelig kommersielt ikke avtalt).
- **Produktflate:** dedikert Møterom-portal på `fhh.digilist.no` (ikke marketplace).
- **Tilgang:** åpen katalog for eksterne; innlogging før booking; interne med godkjent prisgruppe.
- **Første byggetrinn i piloten:** bookingmotor med soner (K02), fire priskategorier + billigste gyldige pris (K03/K05), organisasjonsgodkjenning (K04), vilkår/avbestilling 5/30 (K06), grunnleggende admin (K07).
- **Senere i pilot / fase 2:** catering + Mamas Mat-flyt, Service Crew, infoskjerm, CSV/regnskap.
- **Utenfor første pilot med mindre avtalt:** PowerOffice API, Welcome Workdays, full nettstedserstatning for frivillighetenshus.no.

## Opplæring og ansvar

| Part                | Ansvar                                                                            |
| ------------------- | --------------------------------------------------------------------------------- |
| Xala                | Portal, Digilist-tenant, P0-regler, opplæring av admin                            |
| Frivillighetens Hus | Rommatrise, prisark, org-lister, vilkår, beslutningstaker, LoopBooking-oppsigelse |
| Mamas Mat           | Produkter, endringsfrister, ønsket arbeidsflate (mobil/Sheets)                    |

## Aksept før produksjon

Pilot godkjennes når akseptscenariene i møtereferatet §15 og funksjonsmatrisen for P0 er verifisert på DEV/live uten demo-fallback.
